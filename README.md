# 🚗 Vehicle Rental Management System

A Python-based **Vehicle Rental Management System** developed using **Object-Oriented Programming (OOP)** principles. This project allows users to manage vehicles, rent them, return them, track rental history, and calculate total revenue through a simple console-based interface.

---

## 📌 Features

- Add new vehicles
- Display all available vehicles
- Rent a vehicle
- Return a rented vehicle
- View rental history
- Calculate total revenue
- Check vehicle availability
- Console-based menu-driven interface

---

## 🛠️ Technologies Used

- Python 3.x
- Object-Oriented Programming (OOP)

---

## 📚 OOP Concepts Implemented

- ✅ Classes & Objects
- ✅ Abstraction (Abstract Base Class)
- ✅ Inheritance
- ✅ Encapsulation
- ✅ Polymorphism

## 🚀 How to Run

1. Clone the repository

```bash

```

2. Navigate to the project folder

```bash
cd Vehicle-Rental-Management-System
```

3. Run the program

